# Audição Lagoinha Music Toledo

Landing Page moderna para o processo de audição do ministério de louvor da Igreja Batista da Lagoinha Toledo.

## Tecnologias

- React 18
- Vite
- Tailwind CSS
- Framer Motion (animações)

## Como rodar localmente

1. Instale as dependências:
   ```bash
   npm install
   ```

2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Acesse no navegador: `http://localhost:5173`

## Build para produção

```bash
npm run build
```

Os arquivos finais ficarão na pasta `dist/`.

## Personalização

- Altere o link do botão de inscrição no arquivo `src/components/CTA.jsx`.
- Ajuste cores no `tailwind.config.js`.
- Edite textos diretamente nos componentes.

## Deploy

Recomendado: Vercel ou Netlify (arraste a pasta ou conecte o repositório).
